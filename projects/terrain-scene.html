Procedural Terrain Fly-Through

A fractal landscape of trees, small cities, and ocean, rendered with level of detail and frustum culling while the camera flies a spline path through it.

ROLE
Solo developer
CONTEXT
JHU Applied Computer Graphics, Project 2 (Spring 2026)
TECH
C++, OpenGL, GLSL, SDL3
SOURCE
GitHub (coming soon)

OVERVIEW

This project focused on scene optimization and procedural techniques. The scene is a generated landscape dotted with trees and small city clusters, with a textured ocean surface. The camera can be flown freely with WASD and mouse look, or set to follow a predefined flight path that weaves between the cities, so trees visibly change level of detail and get culled as they leave the screen.

TECHNICAL HIGHLIGHTS

  • View frustum culling: the six frustum planes are built from the projection and view matrices using the Gribb-Hartmann method, and bounding volume nodes skip drawing anything outside them.
  • Hierarchical culling: each city cluster sits inside a larger bounding volume, so a whole city is tested before any of its individual buildings.
  • Level of detail: custom cone and sphere classes preload low, medium, and high detail meshes and pick one based on distance from the camera. Trees are built from these and placed procedurally.
  • Fractal terrain: a Diamond-Square height grid with tunable parameters, colored by elevation in the fragment shader.
  • Camera flythrough: a Catmull-Rom spline through hand-placed control points, evaluated with forward differencing. Toggle it with the T key.

CHALLENGES & SOLUTIONS

Getting the terrain colored by height without breaking the lighting took a couple of attempts. A separate terrain shader looked wrong and fought with the lighting, so I instead added a terrain mode to the existing lighting fragment shader that colors by an input height value.

Every spline segment uses the same number of steps, so the camera slows down where control points are close together. I kept this on purpose because it lingers near points of interest.

WHAT'S NEXT

Fixing a small camera jitter at the transitions between spline segments, and optionally scaling steps per segment by length for a constant flight speed.
