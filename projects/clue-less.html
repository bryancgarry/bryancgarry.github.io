OVERVIEW

Clue-less is a simplified, distributed take on Clue where multiple players connect and play the same game together. The project was run like a real software effort: our team wrote the planning documents up front and delivered the game in stages, demoing each one for peer review.

HIGHLIGHTS

  • Modular architecture: separate networking, game logic, and user interface subsystems with defined interactions between them.
  • Incremental delivery: shipped skeletal, minimal, and target system increments, each presented in a peer-reviewed demo.
  • Documentation: a vision document, software requirements specification, and design document guided the build.
