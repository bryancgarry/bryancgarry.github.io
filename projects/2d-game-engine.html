2D Game Engine

A cross-platform 2D game engine written from scratch in C++, used to build Untitled Card Game, a pixel art card battler.

ROLE
Solo developer
CONTEXT
JHU Computer Gaming Engines (Spring 2025)
TECH
C++, SDL3, FMOD, CMake
SOURCE
GitHub (coming soon)

OVERVIEW

Instead of using an off-the-shelf engine, I built the core systems a 2D game needs myself, then used them to make a complete game. Untitled Card Game is a turn-based pixel art card battler where you face an opponent in tactical matches and can browse the cards in your deck.

ENGINE SYSTEMS

  • Game loop: a real-time loop that updates and draws every frame.
  • Rendering and animation: sprite drawing, sprite animation, and scrolling backgrounds using SDL3.
  • Input: mouse clicks for menus, drag-and-drop for playing cards, mouse wheel scrolling on the collection page, and keyboard shortcuts to pause (P), return to the menu (B), or quit (Esc).
  • Collision: collision detection between game objects.
  • Audio: audio playback and feedback through FMOD.
  • Persistence: a saved game state that keeps both players' hands and point totals, so a match can be continued later.
  • Data-driven setup: a game config file defines each player's starting hand.
  • Build: a CMake build so the engine compiles across platforms.

THE GAME

Each round, the player and the opponent both choose a card to play. Once both are locked in, the cards battle and the higher attack score wins the round. The first to win three rounds wins the match.

The game draws on card games I love, including Balatro, Inscryption, Gwent from The Witcher, Hearthstone, Pokémon TCG Pocket, and Super Auto Pets.
