SpaceTime 3D

A 3D solar system where a wireframe spacetime grid sinks beneath each planet based on its mass, visualizing how gravity bends space.

ROLE
Solo developer
CONTEXT
JHU Computer Graphics, final project (Fall 2025)
TECH
C++, OpenGL, GLSL, SDL3
SOURCE
GitHub (coming soon)

OVERVIEW

Inspired by the classic rubber-sheet gravity demonstration and by Kerbal Space Program, this project renders a solar system above a wireframe grid that sinks beneath each body. Heavier bodies carve deeper wells, and the planets move along curved orbital paths, so the grid reshapes itself as they travel.

TECHNICAL HIGHLIGHTS

  • Spacetime grid: an extruded surface of interconnected vertices drawn with GL_LINES. Each vertex is displaced using every body's mass with F = G·M / r², and the positions are recomputed every draw call.
  • Multi-texture planets: extra textures are passed to the shader as sampler2D uniforms. Day and night maps are blended from the sun's position and each fragment's normal, a cloud map is layered over the terrain, and the final color is boosted so the night side stays readable.
  • Skybox: a cubemap cube centered on the camera. The vertex shader sets gl_Position = pos.xyww so its depth is always at the far plane and it draws behind everything else.
  • Animation: planets travel along curved paths, all organized in a custom scene graph.
